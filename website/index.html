03 — Workflow

From terminal to source files

One command connects your running app to a visual editing layer.

  1. 01

    Detect

    Scan package.json, config files, and directory layout to identify your framework and dev command.

  2. 02

    Attach

    Start your project's dev server or connect to one already running on your machine.

  3. 03

    Proxy & Inject

    Serve the app through Reframe at localhost:4400 and inject the browser client — toolbar, selection, edit panels.

  4. 04

    Map & Write

    Link DOM elements to source locations. Approved edits persist to disk with visual history checkpoints.

04 — Capabilities

Everything you need to edit visually

  • Visual editing

    Select elements, resize and restyle them, edit text inline. Move handles and design panel controls map to real CSS properties.

  • Source mapping

    DOM nodes linked to real file locations with confidence levels — exact, probable, or ambiguous — before any write.

  • Codex generate

    Describe structural changes in natural language. Codex receives structured context — component, source location, Design DNA.

  • Visual history

    Screenshot-first history with prompts, changed files, and local Git checkpoints. Undo and restore any accepted state.

  • Annotations

    Persistent comment pins anchored to real components. Collaborate with teammates on the live page, not stale mockups.

  • Design DNA

    Detected tokens, components, and rules keep AI edits consistent with your project's design language.

  • Figma paste

    Paste Figma CSS directly onto elements. Reframe parses layer styles and applies them to mapped source files.
